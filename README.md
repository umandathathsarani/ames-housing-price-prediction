# Ames Housing Price Prediction

Machine learning project for predicting residential property prices using the Ames Housing dataset, with regression model comparison and property valuation feature analysis.

## Objective

The primary objective of this project is to build a supervised Machine Learning regression system capable of predicting the expected sale price of a residential property based on its characteristics.

A secondary objective is to perform a valuation feature analysis to identify which property characteristics are most influential in determining residential property prices.

## Dataset

This project uses the **Ames Housing / House Prices dataset**.
*   **Source**: The dataset contains real estate data from Ames, Iowa. It is widely known from the Kaggle "House Prices - Advanced Regression Techniques" competition.
*   **Target Variable**: `SalePrice`

## Machine Learning Task

Supervised Regression

## Models Implemented

*   **Dummy Regressor** (Baseline)
*   **Linear Regression**
*   **Random Forest Regressor**
*   **Gradient Boosting Regressor**
*   **Extra Trees Regressor**

## Evaluation Metrics

The models are evaluated using the following regression metrics:
*   **MAE (Mean Absolute Error)**: Measures the average magnitude of the errors in a set of predictions, without considering their direction.
*   **RMSE (Root Mean Squared Error)**: A quadratic scoring rule that also measures the average magnitude of the error. It gives a relatively high weight to large errors.
*   **R² (Coefficient of Determination)**: Provides an indication of the goodness of fit and therefore a measure of how well unseen samples are likely to be predicted by the model.

2.  Place the `train.csv` and `test.csv` (and optionally `data_description.txt` and `sample_submission.csv`) inside the `data/` directory.
3.  The dataset is ignored by Git using `.gitignore` to prevent large files from being pushed to the repository.

## Running the Notebook

To explore the analysis and run the models, launch Jupyter Notebook:

```bash

```
Run the notebook cells from top to bottom to reproduce the results.

## Results

After executing the complete machine learning pipeline and hyperparameter tuning, the final evaluation reveals the best performing model to be the **Tuned Gradient Boosting Regressor**. The actual model results can be viewed inside the Jupyter Notebook.

The feature importance analysis highlighted that the most influential characteristics for predicting price are the total living area (`TotalSF` and `GrLivArea`), the overall material and finish quality (`OverallQual`), and the age of the property (`PropertyAge` / `YearBuilt`).

## Limitations

*   **Market Context**: The dataset relies on historical property sales data. Machine learning models assume historical patterns will continue, making the model potentially sensitive to broad economic shifts in the housing market.
*   **Geographic Scope**: The predictions are geographically limited to Ames, Iowa. The features and their corresponding price impacts cannot be applied directly to other cities.
*   **Prediction Uncertainty**: There is inherent uncertainty in the model's predictions, particularly for properties at the extreme low or high ends of the price spectrum.

## Disclaimer

The predictions generated by this machine learning model are estimates based on historical data. They should be used as a supplementary tool to guide analysis and should not be treated as guaranteed property valuations or formal financial advice.
